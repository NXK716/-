# 钓鱼链接模拟与安全意识演示平台

## ⚠️ 重要声明

**本系统仅供安全教育和授权内部测试使用，严禁任何非法用途！**

这是一个用于网络安全意识教育的模拟钓鱼网站平台，旨在帮助组织和个人了解网络钓鱼攻击的危害，提高安全防范意识。

## 项目概述

该平台允许管理员生成唯一的模拟钓鱼链接，当用户点击这些链接时：
- 系统会记录访问者的设备信息（IP地址、地理位置、设备类型、操作系统、浏览器等）
- 访问者会看到一个醒目的警告页面，告知其"已受骗"并显示被记录的信息
- 所有数据仅用于教育目的，不收集任何敏感隐私信息

## 功能特性

### 管理员后台
- 🔐 密码保护的管理员面板
- 🔗 一键生成唯一的钓鱼链接
- 📊 实时查看点击记录仪表板
- 🌍 基于 IP 的地理位置查询
- 📱 设备类型自动识别（手机/平板/电脑）

### 钓鱼链接页面
- ⚠️ 醒目的红/黄色调警告页面
- 📋 动态展示被记录的设备和位置信息
- 🛡️ 安全意识教育提示
- ⚖️ 明确的免责声明

## 技术栈

- **后端框架**: Flask (Python)
- **数据库**: SQLite (零配置)
- **User-Agent 解析**: user-agents
- **地理位置查询**: ip-api.com (免费 API)
- **前端**: HTML5 + CSS3 + JavaScript (响应式设计)


## 使用说明

### 管理员操作

1. **访问管理面板**
   - 打开浏览器访问: `http://127.0.0.1:5000/admin`
   - 输入密码登录（默认密码: `admin123`）

2. **生成钓鱼链接**
   - 点击"生成新链接"按钮
   - 系统会生成一个唯一的 URL
   - 点击"复制链接"按钮复制链接

3. **查看点击记录**
   - 在管理面板下方查看实时点击记录
   - 记录包含：时间、IP、位置、设备类型、操作系统、浏览器等
   - 数据每 30 秒自动刷新，也可手动点击"刷新数据"

### 测试钓鱼链接

1. 将生成的链接发送给测试对象（或在浏览器中直接访问）
2. 访问者会看到警告页面，显示其被记录的信息
3. 返回管理面板查看新增的访问记录

## 数据模型

### links 表
存储生成的钓鱼链接
- `id`: 主键
- `unique_id`: 唯一标识符 (UUID)
- `created_at`: 创建时间

### visits 表
存储访问记录
- `id`: 主键
- `link_id`: 关联的链接 ID
- `timestamp`: 访问时间
- `ip`: 访问者 IP 地址
- `user_agent`: User-Agent 字符串
- `device_type`: 设备类型（手机/平板/电脑）
- `os`: 操作系统及版本
- `browser`: 浏览器及版本
- `geo_location`: 地理位置（城市, 国家）

## 安全与隐私

### 数据收集范围
本系统**仅**记录以下非敏感信息：
- IP 地址
- User-Agent 字符串
- 基于 User-Agent 解析的设备信息
- 基于 IP 查询的大致地理位置

### 不收集的数据
本系统**绝不**收集：
- Cookie 数据
- 表单提交内容
- 密码或其他认证信息
- 个人身份信息（PII）
- 浏览器历史记录
- 任何其他敏感数据

### 地理位置服务
- 使用免费的 ip-api.com 服务
- 对于本地地址（127.0.0.1）显示"本地地址"
- 查询失败时显示"位置获取失败"
- 注意：该免费 API 有频率限制

## 常见问题

### 1. 如何修改管理员密码？
通过环境变量设置：
```bash
export ADMIN_PASSWORD=new_password
python app.py
```

### 2. 地理位置显示"获取失败"怎么办？
- 检查网络连接是否正常
- ip-api.com 可能有访问频率限制
- 某些 IP 地址可能无法查询到位置信息

### 3. 如何重置数据库？
删除 `phishing_simulator.db` 文件，重启应用会自动创建新数据库。

### 4. 可以部署到生产环境吗？
本系统仅用于教育和内部测试，不建议部署到公开的生产环境。如需部署，请：
- 修改默认密码和密钥
- 使用 HTTPS
- 添加速率限制
- 遵守当地法律法规
